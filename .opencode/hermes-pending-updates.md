### 2026-08-01g addendum 2 — Single-pass sweep: fixed visible loop reset

- **Feedback (Gregory):** liked the gradient sweep single-pass variant, asked for the infinite loop to wrap smoothly with no visible reset.
- **Root cause:** `hp-gradient-loop` paired `background-size: 260%` with an end position of `-260%`. CSS's background-position percentage formula is `(container - size) * (pct/100)`, which is not a 1:1 pixel mapping once size exceeds 100% -- for that size/position pairing the net shift over one cycle overshot a full tile-width, so the loop visibly snapped back at each restart instead of wrapping.
- **Fix:** switched to the standard seamless-loop pairing -- `background-size: 200%` with the loop's end position at exactly `-200%` -- which the same formula resolves to precisely one tile-width of net movement, making the end frame pixel-identical to the start frame under `background-repeat: repeat`. Shared by both `.hp-gradient-text`-based sweep variants (line-by-line and single-pass), since they use the same `hp-gradient-loop` keyframe.
- **Verification:** temporary Playwright install again (`--no-save`, removed after), captured cropped screenshots of the single-pass variant across two full 5.5s loop cycles, specifically bracketing both loop-boundary instants (5.3s/5.5s/5.7s and 11.0s/11.3s/11.7s at 200ms resolution) -- frames immediately before/at/after each boundary are visually identical, no jump. Mid-cycle frames (0s vs 2.5s vs matching points in the second cycle) show the gradient smoothly continuing to drift through its full colour range, confirming continuous motion rather than a stall. Zero console/page errors. Re-ran full suite after: 292/292 tests, clean `npm run build`, `headline-preview` absent from `dist/`.
- Files changed: `src/pages/dev/heroHeadlinePreview.css` (`.hp-gradient-text` background-size 260% -> 200%, `hp-gradient-loop` end position -260% -> -200%, with a comment explaining the seamless-loop math so it isn't re-broken later), `src/pages/dev/HeroHeadlinePreview.tsx` (summary copy for the single-pass variant updated to note the fix).
